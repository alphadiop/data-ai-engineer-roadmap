### Le data lineage est la représentation des flux de données permettant de tracer 
- [ ] l'origine, 
- [ ] les transformations 
- [ ] et les consommations d'une donnée à travers un système d'information.*
- [ ] Lineage = traçabilité des données
- [ ] Source -> Bronze -> Silver -> Gold -> Dashboard


### Databricks
- [ ] Avec le catalogue unifié de Databricks, le lineage peut être visualisé automatiquement pour les tables gérées dans Unity Catalog
- [ ] Tu peux voir : quelles tables alimentent une table
- [ ] Tu peux voir : quels notebooks ou jobs l'ont créée
- [ ] Tu peux voir : quelles tables en dépendent
- [ ] Tu peux voir : parfois même le lineage au niveau des colonnes
